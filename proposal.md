

# Title
Interactive Digital Art Generator

## Repository
https://github.com/TheCorgineer/Logan-Chase-Final-Project-Proposal.git

## Description
A python program that allows the user to create a customized animated digital artwork. The program will generate visuals using different patterns and animation styles, allowing users to interact with and change the appearance of their artwork. The finished program will have a window displaying the generated artwork, along with controls that let users switch between visual styles, change colors, adjust animation speed, and save their creations as images. The artwork will be generated in real time using Python and the Pygame library. Pygame will be used to create the display window, draw shapes and particles, handle user input, and animate the different visual effects.


## Features
- Feature 1: Multiple Generated Style
    - The style of the generation can be chnaged, like particle trial, digital rain, and geometric patterns.
    - Users will be able to switch between the styles while using the program.
- Feature 2: Color Customization
    - The user can choose different colors and color palettes for the generation.
    - Color will effect the particles, characters, shapes, and backgrounds.
- Feature 3: Animation Controls
    - The aniamtion can be ajusted by the user like speed of the animation.
    - Users can change the size or amount of elements.
    - Users can pause and resume the animation if they want to make changes
  Feature 4: Saving Artwork
    - Users will be able to save a PNG file of their artwork with the Pygame image saving feature.

## Challenges
- Creating multiple generation styles that look different and work correctly.
- Making the animations run smoothly while allowing users to change their settings.
- Creating controls that are simple easy to understand and use.
- Making sure the program can save the generated artwork correctly.

## Outcomes
Ideal Outcome:
- A fully working interactive art generator that includes all three visual styles, color customization, animation controls, and the ability to save artwork. Users will be able to experiment with different settings and create unique animated digital artwork.

Minimal Viable Outcome:
- A working program that generates a custom image with color and animation customization.
