

# Title
Interactive Art

## Repository
https://github.com/TheCorgineer/Logan-Chase-Final-Project-Proposal.git

## Description
A python program that allows the user to create a customized animated digital artwork. It generates the patterns and lets the user alter things like color and animation.

## Features
- Feature 1: Generated Style
    - The style of the generation can be chnaged, like particle trial, digital rain, and geometric patterns.
- Feature 2: Color
    - The user can choose different colors and color palettes for the generation.
- Feature 3: Animation 
    - The aniamtion can be ajusted by the user to effect stuff like speed.

## Challenges
- How to create different patterns for the image to be generated in.
- How to create more aniamtions and moving visual effects.
- Creating controls that allow the user to customize the output.

## Outcomes
Ideal Outcome:
- A program that allows the user to generated a custom aniamted image with enought customization options to make it interesting and fun to play around with.

Minimal Viable Outcome:
- A working program that generates a custom image with color and animation customization.
